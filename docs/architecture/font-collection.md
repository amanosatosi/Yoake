# Font collection

The existing ASS model is the authority. `FontUsageSnapshot` copies only immutable style/font/text values on the UI thread. Invalid timing/margin drafts are retained; the scanner needs only text and style, and normalizes physical newlines in its private projection. The shared structured tokenizer handles override blocks, drawing state, escapes and furigana; source, selection, draft, media and undo are never modified. Unused style checking is an explicit option, disabled by default.

The document owns the report/cache, cancellation source and publication lease. Cache identity includes document revision, draft revision and scan options. No media lifetime is attached to this job. Source/draft changes, tab switching, Save As, close and shutdown invalidate its publication lease and cancel work. Native resolution and copying run through the existing background-job service. Progress is dispatched to the UI and is ignored after the originating job/document becomes obsolete. Log changes do not trigger another font-system scan.

`WindowsFontFileResolver` owns DirectWrite and optional GDI resources entirely behind the native boundary. Static vtable calls and source-generated Win32 imports are NativeAOT safe. Exact localized family/full-name matching is tried first; process-private fonts use the supported GDI→DirectWrite bridge, with exact name-table alias validation. A substituted face is reported and never copied as the missing request. Actual glyph indexes, native simulations, collection indexes and local-file loader keys supply real metadata. No new subtitle renderer, decoder or font download path exists.

OpenType name/OS/2 metadata is bounded and handles TTF, CFF/OpenType signatures and TTC collections. All collection faces participate in embedding restrictions. Missing rights metadata is a warning, not permission. Copying requires the user's redistribution acknowledgement and excludes restricted/bitmap-only embedding files. Font presence/embedding bits do not establish redistribution rights.

Whole physical files are deduplicated, streamed and checked for changes. Colliding basenames use content hashes. A complete collection is staged on the destination filesystem and atomically renamed to a new `fonts`/`fonts-2` directory, or a collision-safe ZIP. No existing output is overwritten; failed/canceled/obsolete work cleans its owned staging path. The license notice/report is part of the output. Script-folder mode uses the script's parent directory and is unavailable for unsaved documents. Windows has no symlink mode, matching upstream 3.2.2.

The separate packaged acceptance registers controlled renamed OFL test fonts **privately in the test process**, never in normal product operation. It verifies real Windows TTF/TTC face/file/glyph discovery, native menus/dialog/keyboard, all four modes, exact output bytes and cancellation while retaining an invalid draft and the existing media session. Fixture provenance and modifications are in `ci/create_font_collector_fixtures.py`; no runtime font dependency is added.
