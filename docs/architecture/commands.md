# Command system

Every semantic action has a stable slash-separated ID and metadata. The `CommandRegistry` owns registration, availability, checked state and invocation. UI adapters are deliberately thin and contain no business action logic.

Command failures are contained at the registry boundary, logged through `IAppLog`, and surfaced via `CommandFailed`; they must not escape through `ICommand.Execute`. `RegistryCommand` treats Avalonia as a UI adapter: command-state notifications are marshalled onto `Dispatcher.UIThread` before raising `CanExecuteChanged`. Core command execution stays Avalonia-free and may be invoked from non-UI contexts.

Menus, toolbar buttons, context menus, hotkeys, future command palette, and extension bridges should converge on the registry. IDs are compatibility surface: rename them only with migration intent.

`AppCommand.GetLabel(context)` and `GetDescription(context)` optionally resolve document-contextual display/help text while keeping immutable metadata as the catalog fallback. UI controls must query the command rather than duplicate history names or other semantic state. `RegistryCommand` exposes observable `Label`, `Description`, and `IsChecked`, and refreshes them with availability on the UI dispatcher. Undo/redo menus use these labels; visual-tool and vector-mode commands own their radio state. Direct vector-mode invocation also selects the existing vector-clip tool, so command palette/hotkey invocation has the same useful result as its toolbar.

Native window close requests and the File/keyboard Exit action invoke `app/exit`. Its semantic action runs the existing per-document unsaved/cancel/save workflow and requests presentation closure only after success. The window retains native decorations and performs no document mutation in its close event. Toolbar visibility is a persisted checked presentation command; one toolbar region collapses its command-bar row while retaining the workspace. The log command opens a bounded, asynchronous UTF-8 tail viewer with refresh/copy and cancellation on close; errors return to the main registry/log boundary.

## Grid sort and presentation operations

`grid/sort/{start,end,style,actor,effect,layer}` and `/selected` own the sort action. Selected sorts operate on contiguous selected blocks separately, matching the exact Aegisub implementation. Equal keys retain source order; text keys compare Unicode scalar values. Snapshot capture reads one explicit editor on the caller thread. A cancellable background job calculates only captured immutable keys. Applying the result checks the original editor and document revision, then moves existing records through one undo operation. Unknown fields, format associations and non-event source slots survive. Bulk collection reset is guarded by the existing selection synchronization boundary so the active line and selected record references remain intact.

Each document owns its current editing cancellation token. Draft/document changes, document close, replacement work and disposal cancel obsolete work; `editor/cancel-operation` exposes user cancellation. This token does not represent another editor/session or timeline. Results for closed or changed documents cannot overwrite later edits.

`grid/tags/show`, `grid/tags/simplify`, `grid/tags/hide` and `grid/tag/cycle_hiding` change only the persisted display mode. `SubtitleGridText` projects the draft-aware display source for realized rows through the structured syntax tokenizer. Its inheritable attached display property avoids per-record settings and whole-document reparsing. Exact source, unknown tags, Mangetsu syntax, drafts and undo history remain unchanged. Escaped braces and incomplete blocks remain visible.

## Transactional line operations

Modern frame split commands own the imported Ctrl-D/Ctrl-Shift-D actions. Each selected contiguous block is duplicated immediately after itself, and every copy is selected. Timing edits and structural insertion form one rollback-capable transaction. Splitting at a zero-duration edge or outside a line creates a one-frame copy rather than corrupting the original duration.

The cursor split commands separately expose preserve, grapheme-estimated and current-frame timing. Structured override/escape boundaries and grapheme clusters cannot be cut in half. The new segment carries exact prior override blocks while excluding preceding karaoke timing tags; unknown and Mangetsu tags remain intact. Join variants distinguish spaces, first-text retention, modern duration-based karaoke and Yoake's existing line-break behavior. Clearing visible text retains structured overrides, comments and drawing sections. All actions route through the existing per-document editor/undo boundary.

## Document-local search

Find/Find Next/Find-Replace use shared registry actions and the same contextual defaults as the rest of the editor. `RegistryCommand` can obtain presentation parameters at execution time through an optional factory, keeping controls free of editing semantics. Modeless search windows retain an explicit document ID and original selected-row scope. They reuse one window per document, disable actions when a different tab is active, cancel obsolete input/work on close or context change, and highlight the source through a presentation notification which retains keyboard focus.

Search captures field strings and comment metadata before background work. Text, style, actor and effect fields are supported. Visible-text projection maps matches to exact source spans; replacing across tags retains protected override/drawing/furigana syntax. Unicode grapheme boundaries constrain matches, invalid surrogate replacement is rejected, regex work has a timeout, and cancellation is checked during matching and output construction. Replace-all constructs output in a linear pass per line and applies only after all ownership/staleness checks, in one rollback-capable undo transaction. No search operation normalizes source as a side effect. Raw-source mode is explicit in the UI. Preferences use the source-generated application settings model; result/scope/cancellation state belongs to the existing document lifetime.

Invalid regex syntax is translated at construction into an `ArgumentException` with an actionable message and the original parser error as its inner exception. Validation precedes committing a draft; the command/window reports the error without changing subtitle source, selection or undo history.

## Timing calculation and Shift Times

`SubtitleTimingSnapshot` captures the existing editor's record identities, exact endpoint strings and selected flags, plus a validated immutable copy of a pending draft when present. Cancellable calculation reads these immutable values and the captured central `FrameTiming`; it never reads a current document/provider from a worker. `ApplyTiming` rejects foreign/stale plans and applies all changes in one rollback-capable undo transaction. A canceled or invalid calculation retains the original draft and history. A successful calculation applies the draft and timing as one undo operation; the normal edit-burst timer is paused during calculation and resumed only if an unfinished draft remains. Unchanged endpoint source is retained exactly. Invalid ranges are rejected before any rows change; negative endpoints clamp at zero and changed endpoints use the audited ASS centisecond rounding.

`time/continuous/start` and `/end` require a contiguous block; a single row uses its preceding/following outside neighbor. `time/snap/start_video`, `/end_video`, `/scene` and `time/frame/current` operate on the actual selection through the central VFR START/END boundaries. Video-only actions are disabled without valid video/frame data. The existing current-time actions remain available independently; the imported Ctrl-3/Ctrl-4 defaults resolve to the new exact video semantics.

Shift Times exposes time/frame units, all/selected/selection-onward scopes, start/end/both choices, direction, saved preferences and up to 50 reusable history entries. Its window captures one explicit document/selection and invokes shared Apply, Cancel and Clear History commands through parameter adapters. Expensive calculations are owned by that document's existing editing cancellation token; close, cancellation, stale revision or document switch cannot publish partial results. A dedicated packaged timing process tests real Ctrl-I, actual dialog controls, invalid input, IME Enter/Escape, multi-selection Ctrl-3/Ctrl-4, exact undo and provider retention; a second launch checks persisted preferences/history. Startup and contextual-hotkey acceptance remain separate and unchanged.
