# Karaoke timing ownership

`ToshikiTimingPlan` owns immutable lossless source mapping plus explicit text cuts, tag choices and audio boundaries. It holds no provider, pointer, view or playback clock. The balanced top-level tag scanner is shared with Automation; the Lua compatibility result remains unchanged. Reading offsets support renderer furigana, opaque base-side overrides and grapheme-safe cuts. Unknown overrides/drawings are copied unchanged.

Each document owns its mode and per-event plans. Preview overlays the selected plan's text/start/end onto the same pending-aware Mangetsu preview snapshot used by frame export. Audio playback uses the existing sample-bounded range and central clock. Waveform and spectrum draw the same slots and markers; capture loss, Escape, focus/tab/media changes roll back the pointer checkpoint. No native pointer is persisted. Keyboard timing commands use their existing stable IDs and context routing.

Commit validates the existing raw draft, source identity and ownership before one rollback-by-default subtitle transaction. Editor draft fields are included in that operation, preserving custom Format columns and unrelated source records. Foreign event edits invalidate obsolete plans; ordinary matching draft publication rebases them. Pending plans retain dirty/recovery identity across tabs and Audio Close. Mode exit does not publish timing. A pending plan with a modified text draft blocks implicit draft publication until Commit or Cancel resolves it.

The atomic recovery metadata contains typed row/source/cut/tag/boundary/recut/cursor snapshots, validated against recovered document row bounds and safe source cuts. Committed ASS, attachments and encoding stay in the unchanged source entry; raw invalid draft fields remain in their own entry. Recovery opens another unsaved tab and restores timing plans without native media. Reopening Audio resumes them. Source-generated JSON keeps this NativeAOT-safe. Existing recovery history, cancellation and publication fencing apply unchanged.
