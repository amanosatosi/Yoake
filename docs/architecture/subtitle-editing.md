# Lossless subtitle editing boundary

`AssDocument` owns an ordered source graph. A source node retains its raw line, its own newline sequence, and optionally a structured event/style record. Records retain their prefix spelling, local Format and raw field strings, including fields the editor does not understand. The public event/style collections are read-only observable views over that graph.

Parsing consumes fields before Text from the left and fields after Text from the right. This permits nonstandard Format order while retaining commas inside Text. Malformed/unknown source remains present. Ordinary field edits only change the explicitly edited fields. Serialization is cached by document revision. No override-tag parsing is involved in normal text edits.

Insert/delete/move work on source nodes, never on global string replacement. Moves swap known records at event/style slots and leave unrelated source lines in place. When a record's schema differs from a slot's Format, serialization emits its local Format and restores the original Format afterward, preserving the context of unknown record types. Structural operations capture source topology references for undo; field operations capture the affected record's small field array. Bulk operations defer collection synchronization until the batch completes. They do not reload/reparse the file or replace every row view model.

`SubtitleEditor` owns one document and one `UndoManager`. It validates cross-document ownership. UI controls bind to `EventEditDraft`, never directly to the document's mutable fields. Commit validates first, then applies a semantic transaction. Selection/tab navigation commits valid drafts; invalid drafts remain selected. Newlines become `\N` only in edited Text. Grapheme-aware splitting avoids override blocks and ASS text escapes. Splitting repeats leading override blocks on the second line; it is not a karaoke/animation retiming engine.

`UndoManager` identifies committed history states and its saved state, so undoing to a savepoint clears dirty state and branching does not accidentally match a previously saved state. Transactions retain rollback-by-default behavior. Adjacent field operations on the same record merge inside a transaction, keeping long gestures bounded. UI draft dirty state supplements the committed state without creating per-keystroke undo entries.

`AssVisualTags` scans source spans within override blocks and balances parentheses. Nested transform arguments are skipped, so a transformed position/clip is not mistaken for the static tag being manipulated. Visual edits splice the targeted source span and preserve surrounding bytes. Static position targets the first tag, matching Mangetsu; movement and relative/expression positioning are explicitly refused by this first tool. Vector clips retain the integer drawing scale; handles convert coordinates using `2^(scale-1)` and replace only coordinate tokens. Vector control polygons are editing aids; Mangetsu remains authoritative for the rendered curve.

Styles retain all Format fields. Rename updates exact matching event Style fields and complete top-level `\rStyleName` spans in the same transaction. Delete detects both types of reference and requires a surviving replacement when referenced. Literal text, incomplete blocks, nested transform arguments and unrelated unknown syntax are preserved. Bulk clipboard/import/transfer/duplicate operations prevalidate and deterministically suffix conflicting names, then insert in one structural undo operation. Bulk reorder/sort replace only known style slots, preserving unknown sections and Format context. Script Info edits operate on individual keys and preserve unrelated entries/sections.

Event drafts now provide live presentation without changing saved source. AssEvent's Display properties expose a detached preview record; those notifications never advance document revision. Grid rows stay virtualized and fixed at 30 DIP. `SerializePreview` splices the edited record into a cached serialized document using cached record spans, preserving other source verbatim without reparsing. The view model caches that preview source by preview revision. Typing debounces Mangetsu feedback by 30 ms; stale render completions cannot replace newer revisions. A 900 ms idle boundary finalizes a validated editing burst as one undo transaction. Line/tab switching, save and explicit finish also finalize; Escape discards the pending burst. Invalid drafts remain editable and block navigation/finalization.

AssTextBox delegates shaping, IME and ordinary navigation to Avalonia. Only Up on the first shaped visual line and Down on the final shaped visual line override movement, including Shift selection anchors. Preedit bypasses this override.

Saving preserves UTF BOM/endianness and each source line ending, and replaces the destination only after a temporary file is written and flushed. Legacy code-page files are rejected before editing. No new runtime dependency or reflection-based serialization/editor framework is used.
