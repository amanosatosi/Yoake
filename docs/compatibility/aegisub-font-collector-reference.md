# Fonts Collector source audit

Research record; implementation and packaged verification must be recorded separately before promoting `tool/font_collector`.

Primary baseline is the supplied Aegisub 3.2.2 archive: `src/command/tool.cpp` (`tool_font_collector`), `src/dialog_fonts_collector.cpp` (dialog, modes, background worker and copy reporting), `src/font_file_lister.cpp` (style/override/text-segment usage), `src/font_file_lister.h`, and `src/font_file_lister_fontconfig.cpp` (exact family/full-name restricted matching, requested weight/slant, glyph coverage, physical paths and fake bold/italic). This archive does **not** contain `font_file_lister_gdi.cpp`; the later supplied 3.5 version was inspected as additional Windows API evidence, not as a substitute compatibility baseline.

3.2.2 ignores comment events, requires the event's style to exist, processes top-level `r`, `b`, `i`, and `fn` per plain-text segment, excludes drawings/override syntax from glyph requirements, skips `N`/`n` escapes and maps `h` to U+00A0. It records Unicode scalar values and deduplicates both font requests and physical files. Reset tag fallback parameters in this baseline use the original line style. Fontconfig limits matching to fonts with an actual case-insensitive family or full-name match before choosing weight/slant; an arbitrary fallback is never success. Vertical-family `@` prefixes are stripped for file lookup. It reports missing glyphs and absent real bold/italic variants. Unused styles without text are not copied in upstream; a Yoake all-style check must state its deliberate broader reporting behavior.

Windows modes are check-only, copy to selected folder, copy to script directory and copy to ZIP. Check is the non-destructive starting action. Script-directory mode is unavailable for unsaved documents. The symlink mode is compiled only outside Windows in 3.2.2 and need not be exposed by Yoake's Windows collector. Existing destination basenames are skipped upstream; Yoake should compare/deduplicate content and use explicit collision-safe publication. Worker errors are reported, not used to modify subtitle source.

Later Windows evidence (`3.5 src/font_file_lister_gdi.cpp`): supported GDI selection checks the selected face name, then DirectWrite obtains the actual font face, simulations, missing characters, collection index and local font-file reference keys. It releases every HFONT/HDC/COM reference. DirectWrite handles fonts with multiple faces and avoids filename guesses; private AddFontResource fonts may be absent from the system font collection. Exact local-file loader identity is required before interpreting a reference key as a filesystem path.

API layout was cross-checked against Microsoft's `win32metadata/generation/WinSDK/RecompiledIdlHeaders/um/dwrite.h` (observed blob `8ade596ae81d6ed983fb1b6e414a0d40a414bdba`). Use statically declared NativeAOT-safe interop and explicit ownership. OpenType OS/2 embedding bits are useful warnings/restrictions but are not evidence of redistribution permission. Native fixture fonts must be deterministic and legally redistributable; proprietary runner fonts are not an acceptance oracle.

## Implementation awaiting verification

The Yoake implementation uses the shared structured scanner and a read-only document/draft projection. Empty and fn0 resets follow the current Mangetsu default/reset style (confirmed in ass_parse.c blob 4b43f2dcf0222779b1935c8c6deb0ba8f568a532), correcting the older collector fallback behavior. Unused style checking is explicit and disabled by default. All four Windows modes are implemented, with complete-batch atomic folder/ZIP publication, collision-safe naming, cache/revision/lease fences and redistribution acknowledgement. No status promotion is claimed before full CI.

Controlled native fixtures come from googlefonts/cousine commit c0fbdb438443968c884a5c13f5f9bee916a7f89b, fonts/ttf/Cousine-Regular.ttf, Cousine-Bold.ttf, Cousine-Italic.ttf and OFL.txt. Family/full/PostScript names are changed to isolate the native process; glyphs remain unchanged. Regular/Bold are packed into a real TTC with unused zero padding for deterministic cancellation. The OFL version has no Reserved Font Names; its full license and provenance are kept with fixtures. Hashes are verified by the standard-library-only CI generator. There are no runtime dependencies or automatic product font installs/downloads.
